About Us

Learn more about the purpose of the Appliance Energy Consumption Website.

Our Purpose

The Appliance Energy Consumption Website was created to demonstrate how web technologies can be used to present information about household energy consumption.

The website provides information about appliance energy usage and demonstrates basic interactive features using HTML, CSS and JavaScript.

What We Aim to Do

Educate

Provide simple information about household appliance energy consumption.

Inform

Explain some of the factors that affect the amount of electricity appliances consume.

Encourage Awareness

Encourage users to become more aware of their household electricity usage.

Technologies Used

This website demonstrates the use of three core web technologies:

  • HTML – used to structure the webpages.
  • CSS – used to style and format the website.
  • JavaScript – used to provide interactive features.

About This Project

This website was developed as part of COS30045 Data Visualisation. It provides a foundation for future exercises involving interactive data visualisations and JavaScript-based web development.
